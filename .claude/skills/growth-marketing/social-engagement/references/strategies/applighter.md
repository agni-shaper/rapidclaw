# Strategy: Applighter

Distribution + growth angle for **Applighter** (applighter.com) — Shaper Studio's full-stack templates store.

## Status

**STUB.** This strategy needs a brand audit from @sanket. The following is a best-guess scaffold; flag explicitly in any draft that "Applighter voice is still TBD" until this file is filled in.

## Product positioning (provisional)

- **What it is:** Full-stack templates store. Pre-built Next.js / React Native / Stripe / Supabase / Clerk integration boilerplates that compress weeks of setup into minutes.
- **Who it's for:** Indie SaaS founders, agencies, and small teams who want a paying customer in days rather than building the auth/payment/DB plumbing from scratch.
- **Wedge:** "Skip the boilerplate. Start charging in days."

## Topic pillars (provisional)

1. **Full-stack templates** — Next.js + RN + Stripe + Supabase + Clerk combos. Real templates, real code.
2. **Time-to-first-deploy** — how fast a builder gets to a paying customer.
3. **(More pending Sanket's brand audit.)**

## Voice for Applighter drafts (provisional)

- Pragmatic, builder-to-founder. Less "engineering depth", more "what'll get you paid".
- Time-to-value framing. Money-flow concrete examples.
- Pricing transparency — templates have a price, talk about it.
- Cross-brand defaults from `profile.md` still apply (no em-dashes, no buzzwords, concise).

## Platforms (provisional)

Likely overlap with RapidNative but skew more towards:

1. **Indie Hackers** — funnel for SaaS-builder audience.
2. **X (Twitter)** — Sam Altman / indie SaaS / "I built X in a weekend" community.
3. **Reddit** — r/SaaS, r/Entrepreneur, r/indiehackers, r/webdev.
4. **LinkedIn** — selectively, for founder/CTO audiences.
5. **Product Hunt** — scheduled launches per template release.

(Cross-promote with RapidNative on RN-specific channels when templates land in the React Native template category.)

## SEO / content priorities

- "Stripe + Supabase + Next.js template" long-tail.
- "How to launch a SaaS in a weekend" tutorial-funnel content.
- Template-by-template landing pages (each template = its own page).

## Off-platform amplification

- Indie Hackers product posts.
- Awesome lists (`awesome-saas`, `awesome-nextjs`, `awesome-supabase`).
- Cross-promote in the RapidNative GitHub README when templates touch React Native.
